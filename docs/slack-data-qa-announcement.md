🚀 *New demo feature live on the Embedding Playbook*

Until now, giving embedded users access to Tableau Agent meant showing the toolbar — which breaks the seamless app experience most customers want.

The Superstore demo now has a *"Data Q&A"* button that launches Tableau Agent directly from the host app, toolbar completely hidden. Clean embed. Full AI.

One API call: `viz.launchAnalyticsAssistantAsync()`

Your customers no longer have to choose between a polished product UI and Tableau's AI. They get both.
